# 欢迎

后续这里会放置自己的技术文章、学习记录、研究思考以及其他希望长期保存的内容。

## 文章系统

文章使用 Markdown 编写，通过文件头部的元数据管理标题、日期、分类和标签。

以后新增文章时，只需要在 `src/content/articles/` 中增加新的 Markdown 文件即可。
